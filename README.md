# 宇哥 VS 检哥 · 赛博回合制对战

网页端 + Android APK 双端的本地双人 / 人机回合制对战小游戏，纯 HTML5 + CSS3 + 原生 JavaScript 实现，无任何构建依赖，双击即可在浏览器运行。

> 我非常爱戴两位老师，二创内容与现实无关。

## ✨ 玩法

- **双人模式**：本地双人轮流操作
- **人机模式**：可选 AI 控制「检哥」或「宇哥」
- **回合制战斗**：普攻 / 小技能 / 大招，含能量、冷却（CD）、暴击、灼烧/追缴持续伤害、眩晕/减防/虚弱等状态

### 角色与技能

| 角色 | 定位 | 普攻 | 小技能 | 大招 |
|---|---|---|---|---|
| **宇哥** | 高爆发 · 视觉系 | 平A（55~80 物理，15% 暴击，耗 10 能量） | 志哥之怒（立即 140 直伤 + 下次攻击必暴击 + 灼烧 40×3） | 宇哥降临（满血约 450 伤害，血越少越痛，耗 90 能量，带全屏素材演出） |
| **检哥** | 控制 · 策略型 | 精准打击（65~90 物理，稳定，耗 10 能量） | 检哥的凝视（眩晕 1 回合 + 减防 30% + 20 真伤） | 绝对检阅（真实伤害=160+累计受击×50%，护盾+削弱+追缴 44×5，耗 110 能量，带粒子特效） |

## 🚀 使用

### 网页版
直接双击 `index.html`（或拖进任意现代浏览器）即可游玩，无需服务器。

### Android APK
- 直接安装 `android/YuGeJiange.apk`（Android 5.0+）
- 首次启动会弹出二创声明，确认后进入
- 顶栏「ℹ️ 关于」可查看作者与反馈邮箱（点击邮箱自动打开邮件客户端）

## 🔧 从源码构建 APK

需要 JDK 17 + Android SDK（build-tools 34 / platform android-34），本仓库不含工具链：

```powershell
# 1. 把 index.html/style.css/script.js 及图片音效素材放在仓库根目录（已就位）
# 2. 运行构建脚本（自动同步素材、编译、打包、签名）
powershell -ExecutionPolicy Bypass -File android/build.ps1
```

产物输出到 `android/YuGeJiange.apk`。签名密钥 `android/debug.keystore` 由脚本首次运行时自动生成（不随仓库分发）。

## 📁 结构

```
├── index.html / style.css / script.js    # 游戏本体

└── android/
    ├── YuGeJiange.apk                    # 打包好的 APK
    ├── build.ps1                         # 命令行构建脚本（无需 Gradle）
    ├── make-icons.ps1                    # 启动图标生成脚本
    └── app/src/main/                     # Android WebView 封装工程
```
